# Medication Reminder WebApp

แอปเว็บสำหรับแจ้งเตือนการรับประทานยา ทำงานผ่านเว็บเบราว์เซอร์  
ผู้ใช้สามารถตั้งเวลาแจ้งเตือน และมีเสียงแจ้งเตือนเมื่อถึงเวลาที่กำหนด

> หมายเหตุ: โปรเจกต์นี้เป็นโปรเจกต์เพื่อการเรียนรู้และพัฒนาทักษะการเขียนโค้ดของผู้พัฒนา  
> โดยมุ่งเน้นการฝึกใช้ HTML, CSS และ JavaScript

## ภาพรวมของระบบ

Medication Reminder WebApp เป็นเว็บแอปที่ผู้ใช้สามารถเปิดใช้งานผ่านมือถือหรือคอมพิวเตอร์  
เพื่อใช้เป็นตัวช่วยเตือนการรับประทานยาในเวลาที่ตั้งไว้

เทคโนโลยีที่ใช้พัฒนา:
- HTML สำหรับสร้างโครงสร้างหน้าเว็บ
- CSS สำหรับออกแบบและตกแต่งหน้าเว็บ
- JavaScript สำหรับจัดการระบบแจ้งเตือนและเล่นเสียงเตือน

## โครงสร้างไฟล์

- index.html — หน้าเว็บหลัก  
- style.css — ไฟล์จัดรูปแบบและตกแต่งหน้าเว็บ  
- script.js — ไฟล์สคริปต์ควบคุมระบบแจ้งเตือน  
- ไฟล์เสียงแจ้งเตือน  
- รูปภาพประกอบหน้าเว็บ  
- README.md — ไฟล์อธิบายโปรเจกต์  

## วิธีการใช้งาน

1. โคลนโปรเจกต์  
   git clone https://github.com/same-sain/medication_reminder_wedapp.github.io.git

2. เปิดไฟล์ index.html ในเว็บเบราว์เซอร์

3. ตั้งค่าการแจ้งเตือน  
   - เลือกเวลาที่ต้องการแจ้งเตือน  
   - กดปุ่มเพื่อเริ่มระบบแจ้งเตือน  

เมื่อถึงเวลาที่ตั้งไว้:
- ระบบจะแสดงข้อความแจ้งเตือน  
- มีเสียงแจ้งเตือนดังขึ้น  

## ฟีเจอร์หลัก

- ตั้งเวลาแจ้งเตือนการรับประทานยา  
- แจ้งเตือนด้วยเสียง  
- ใช้งานได้ทั้งมือถือและคอมพิวเตอร์  
- ใช้ผ่านเว็บโดยไม่ต้องติดตั้งแอป  

## แนวทางพัฒนาต่อยอด

- บันทึกชื่อยาและรายละเอียด  
- เพิ่มการตั้งเตือนซ้ำ  
- รองรับ Dark Mode  
- เพิ่มปุ่มปิดเสียงหรือเลื่อนแจ้งเตือน
