# 📌 Medication Reminder WedApp

โปรเจกต์เว็บแอปสำหรับ แจ้งเตือนการบริหารยา ผ่านหน้าเว็บ ใช้ HTML, CSS และ JavaScript
ช่วยให้ผู้ใช้ตั้งเวลาการแจ้งเตือนและได้ยินเสียงเตือนเมื่อถึงเวลา

📌 🧠 ภาพรวม

Medication Reminder WedApp เป็นเว็บแอปง่าย ๆ ที่ทำงานบนเบราว์เซอร์
ผู้ใช้สามารถเปิดเว็บนี้บนมือถือหรือคอมพิวเตอร์เพื่อใช้เป็นระบบแจ้งเตือนเมื่อถึงเวลาต้องทานยา

ใช้ HTML/CSS ในการแสดง UI

ใช้ JavaScript ในการจัดการเวลาการเตือน

มีเสียงเตือนเมื่อถึงเวลาที่ตั้งไว้

├── style.css             # CSS สำหรับจัดแต่งหน้าเว็บ
├── script.js             # JavaScript สำหรับระบบแจ้งเตือน
